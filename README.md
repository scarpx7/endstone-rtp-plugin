# Endstone RTP Plugin

Рандомная телепортация (RTP) плагин для Endstone Bedrock сервера.

## Возможности

- **Близкая телепортация** (`/rts`) - телепортирует игрока на короткую дистанцию
- **Далекая телепортация** (`/rta`) - телепортирует игрока на большую дистанцию
- **Уникальные координаты** - система отслеживает использованные локации
- **Безопасные локации** - автоматический поиск земли под игроком
- **Кулдаун** - защита от спама команд
- **Конфигурируемый** - все параметры можно настроить в config.json

## Установка

### Требования
- Python 3.8+
- Endstone server

### Как установить

1. Клонируйте репозиторий:
```bash
git clone https://github.com/scarpx7/endstone-rtp-plugin.git
cd endstone-rtp-plugin
```

2. Установите плагин:
```bash
pip install -e .
```

3. Скопируйте плагин в папку `plugins` вашего сервера

4. Перезагрузите сервер

### Сборка .whl файла

```bash
python setup.py bdist_wheel
```

Итоговый файл будет в папке `dist/`

## Команды

### /rts - Близкая телепортация
Телепортирует игрока на случайное место в пределах указанного радиуса.

```
/rts
```

**Пример:**
```
/rts
✓ Teleported nearby!
X: 1523 Y: 64 Z: -892
```

### /rta - Далекая телепортация
Телепортирует игрока на случайное место на большой дистанции.

```
/rta
```

**Пример:**
```
/rta
✓ Teleported to random location!
X: 5234 Y: 72 Z: 3456
```

## Конфигурация

После первого запуска плагина будет создан файл `plugins/endstone-rtp-plugin/config.json`

```json
{
  "short_range": 100,
  "long_range": 1000,
  "y_min": 0,
  "y_max": 256,
  "safe_ground_search": true,
  "max_attempts": 50,
  "cooldown": 5
}
```

### Параметры конфигурации

| Параметр | Описание | Значение по умолчанию |
|----------|---------|----------------------|
| `short_range` | Радиус близкой телепортации в блоках | 100 |
| `long_range` | Радиус далекой телепортации в блоках | 1000 |
| `y_min` | Минимальная высота спавна | 0 |
| `y_max` | Максимальная высота спавна | 256 |
| `safe_ground_search` | Искать твердую землю для спавна | true |
| `max_attempts` | Максимум попыток найти локацию | 50 |
| `cooldown` | Кулдаун между командами в секундах | 5 |

## Возможные ошибки

### "Could not find a safe location! Try again."
Плагин не смог найти безопасное место для телепортации. Это может происходить в океане или в местах без земли. Попробуйте команду еще раз.

### "Please wait before using RTP again!"
Вы слишком часто используете команду. Подождите указанное в конфиге время (по умолчанию 5 секунд).
