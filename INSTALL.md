# Endstone RTP Plugin - Расширенная документация

## 🎮 Обзор

**Endstone RTP Plugin** - профессиональный плагин случайной телепортации для серверов Minecraft Bedrock Edition на базе Endstone. Плагин включает две команды телепортации с разными радиусами действия и системой отслеживания использованных координат, чтобы не было "конфликтов" спавна на одних и тех же местах.

## ✨ Ключевые особенности

### 1. **Два режима телепортации**
- **`/rts`** (Random Teleport Short) - близкая телепортация до 100 блоков
- **`/rta`** (Random Teleport Any) - дальняя телепортация до 1000 блоков

### 2. **Система отслеживания координат**
- Все использованные координаты записываются в памяти
- Система предотвращает спавн на одних и тех же местах
- При достижении 1000 записей происходит очистка (циклический буфер)

### 3. **Безопасность**
- Автоматический поиск твёрдой земли под игроком
- До 50 попыток найти безопасное место
- Проверка Y-координаты (0-256 по умолчанию)

### 4. **Защита от спама**
- Кулдаун между командами (5 секунд по умолчанию)
- Индивидуальный таймер для каждого игрока

### 5. **Полная конфигурируемость**
- Все параметры настраиваются в `config.json`
- Автоматическое создание конфига при первом запуске

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Endstone server (последняя версия)
- pip (для установки зависимостей)

### Установка

#### Способ 1: Из исходного кода
```bash
git clone https://github.com/scarpx7/endstone-rtp-plugin.git
cd endstone-rtp-plugin
pip install -e .
```

#### Способ 2: Установка из .whl файла
```bash
# Сначала собираем wheel
python build.py

# Затем устанавливаем
pip install dist/endstone_rtp_plugin-*.whl
```

#### Способ 3: Прямое копирование в плагины
```bash
# Скопируйте папку rtp_plugin в папку plugins вашего сервера
cp -r rtp_plugin /path/to/server/plugins/
```

### Первый запуск

1. Запустите сервер Endstone
2. Плагин автоматически создаст папку `plugins/endstone-rtp-plugin/`
3. В этой папке появится файл `config.json`
4. Можно отредактировать конфиг и перезагрузить плагин

## ⚙️ Конфигурация

### Файл конфигурации: `config.json`

```json
{
  "short_range": 100,
  "long_range": 1000,
  "y_min": 0,
  "y_max": 256,
  "safe_ground_search": true,
  "max_attempts": 50,
  "cooldown": 5
}
```

### Описание параметров

| Параметр | Тип | Описание | Рекомендуемое значение |
|----------|-----|---------|------------------------|
| `short_range` | int | Радиус близкой телепортации в блоках | 50-150 |
| `long_range` | int | Радиус дальней телепортации в блоках | 500-5000 |
| `y_min` | int | Минимальная высота спавна | 0 (коренная порода) |
| `y_max` | int | Максимальная высота спавна | 256 (максимум в Bedrock) |
| `safe_ground_search` | bool | Искать твёрдую землю под игроком | true |
| `max_attempts` | int | Макс. попыток найти безопасное место | 30-100 |
| `cooldown` | int | Кулдаун между командами (сек) | 3-10 |

### Примеры конфигурации

#### Для PvP сервера (меньше диапазон)
```json
{
  "short_range": 50,
  "long_range": 300,
  "cooldown": 10,
  "max_attempts": 30
}
```

#### Для Survival сервера (стандартная)
```json
{
  "short_range": 100,
  "long_range": 1000,
  "cooldown": 5,
  "max_attempts": 50
}
```

#### Для RolePlay сервера (большие диапазоны)
```json
{
  "short_range": 200,
  "long_range": 5000,
  "cooldown": 15,
  "max_attempts": 100,
  "y_max": 320
}
```

## 💬 Команды

### `/rts` - Близкая телепортация

**Описание:** Телепортирует игрока на случайное место в пределах `short_range` блоков.

**Использование:**
```
/rts
```

**Результат:**
```
✓ Teleported nearby!
X: 1523 Y: 64 Z: -892
```

**Когда использовать:**
- Исследование местности рядом с домом
- Быстрый переход на небольшое расстояние
- На PvP серверах для быстрого бегства

### `/rta` - Дальняя телепортация

**Описание:** Телепортирует игрока на случайное место на большом расстоянии (до `long_range` блоков).

**Использование:**
```
/rta
```

**Результат:**
```
✓ Teleported to random location!
X: 5234 Y: 72 Z: 3456
```

**Когда использовать:**
- Поиск новых биомов
- Экспедиции на дальние расстояния
- Нахождение редких ресурсов
- Спасение от врагов на большом расстоянии

### Расширение функциональности

Для добавления новой команды:

1. Добавьте параметр в `config.json`
2. Создайте новый класс команды в `commands.py`
3. Зарегистрируйте команду в методе `register_commands()` класса `RTPPlugin`

Пример:
```python
class RTMCommand(Command):
    """Random Teleport Medium command"""
    
    def __init__(self, plugin: RTPPlugin):
        super().__init__("rtm", "Random teleport medium distance")
        self.plugin = plugin
        # ...
```

## 🐛 Решение проблем

### Проблема: "Could not find a safe location! Try again."

**Причины:**
- Игрок находится в океане (нет земли)
- Область полностью заполнена водой
- Недостаточно попыток поиска

**Решение:**
```json
{
  "max_attempts": 100,  // Увеличите количество попыток
  "safe_ground_search": true
}
```

### Проблема: Кулдаун слишком долгий

**Решение:**
```json
{
  "cooldown": 3  // Уменьшите значение кулдауна (в секундах)
}
```

### Проблема: Игроки спавнятся в одних местах

**Проверьте:**
- Что `short_range` или `long_range` достаточно большие
- Что в мире достаточно свободного пространства
- Перезагрузите плагин (очистит кэш координат)

### Проблема: Плагин не загружается

**Решение:**
```bash
# Проверьте установку Endstone
pip show endstone

# Переустановите плагин
pip install --force-reinstall endstone-rtp-plugin

# Проверьте логи сервера на ошибки
```
